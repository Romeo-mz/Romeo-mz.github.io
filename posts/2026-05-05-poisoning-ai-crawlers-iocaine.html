6,970 Requests Served, All Garbage: Running iocaine Against AI Crawlers

May 5, 2026 · Security · AI · DevOps · 6 min read

Every request in that dashboard got the same response: garbage. That's iocaine doing exactly what it promises — and it cost the backend zero requests to do it.

I ran iocaine against a simulated AI crawler swarm and watched 6,970 requests produce 8.46 MiB of plausible-looking nonsense. The crawler followed every link. The links led nowhere real. The backend stayed quiet the entire time.

What iocaine is

Iocaine is a tarpit for AI scrapers. It sits between your reverse proxy and your backend. When it identifies an unwanted visitor, it routes that visitor into an infinite maze of garbage pages, each filled with garbage links that lead to more garbage.

The key design decision is that iocaine doesn't block crawlers — it welcomes them. Blocking teaches bots to evade. Trapping them wastes their resources while yours stay intact. Generating a garbage response costs roughly as much as serving a static file.

Iocaine also poisons the URLs it serves. A crawler that later returns disguised as a real browser can still be identified, because its queue is full of URLs only iocaine hands out.

The setup

Three containers: iocaine 3, Prometheus, and Grafana. Configuration uses KDL, which reads like structured prose and stays out of the way.

The garbage handler loads ai.robots.txt to respect declared opt-outs, then remixes a training corpus into responses:

sources {
  training-corpus "/data/corpus/1984.txt" \
                  "/data/corpus/brave-new-world.txt"
  wordlists "/data/corpus/words.txt"
}

The corpus is 1984 and Brave New World. The choice is deliberate. The garbage looks coherent enough to pass a quick scan but is semantically hollow — exactly the kind of material that degrades a training dataset.

Metrics bind to a separate port (42042), keeping Prometheus scrape traffic off the main garbage-serving path on 42069.

The crawler simulator

To stress-test the setup, I wrote a Python crawler that impersonates real AI bots. It rotates through 27 User-Agent strings — GPTBot, ClaudeBot, CCBot, Bytespider, Applebot-Extended, and the rest — using five concurrent workers with a 0.5-second delay between requests. It follows every link iocaine hands it.

This is the worst case for a tarpit: a persistent, multithreaded crawler that faithfully chases every URL it receives. It doesn't back off. It doesn't time out. It just keeps crawling.

The simulator also exposes its own Prometheus metrics — requests per bot type, response sizes, links discovered, active threads — so Grafana can show both sides of the exchange.

Results

The throughput graph tells a clean story. The crawler starts slow, fills its queue with garbage links, then saturates — climbing from zero to a mean of 8.56 kB/s with a peak of 10.3 kB/s. Once it's in the maze, it never finds its way out.

The 127.0.0.1 host (direct access, bypassing the tarpit) flatlines at 0 B/s throughout. The backend was never reached. 8.46 MiB of garbage generated, zero legitimate responses served.

Garbage outcomes matches total requests exactly. A 100% hit rate.

Why this matters beyond a personal blog

AI crawlers largely disregard robots.txt. They hit sites relentlessly, scrape content for training datasets, and are often indifferent to the server load they cause. IP blocking is a losing game — subnets rotate, and browser-based scrapers piggyback on clean IPs.

Iocaine takes the opposite approach. The longer a crawler runs against it, the more garbage fills the crawler's training queue. The crawler's own persistence works against it.

The same Docker Compose stack that protects a blog scales to a production service. Iocaine's firewall module (added in 3.3.0) can enforce blocks at the nftables level for persistent offenders, without any external tooling. The ai.robots.txt integration handles legitimate bots that declare opt-out support, so real visitors and well-behaved crawlers pass through cleanly.

The setup here took an afternoon. The crawler simulator took a morning. Together they give a clear picture of what iocaine does and how much it costs — which is almost nothing.

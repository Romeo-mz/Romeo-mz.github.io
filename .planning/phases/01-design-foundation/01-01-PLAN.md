  <action>
At the very top of style.css, create a comprehensive :root section with CSS custom properties for all design tokens:

**Color Palette:**
- Base colors: --color-pink-base: #fdc3c6, --color-green-base: #00a36c
- Semantic colors: --color-background (pink), --color-interactive (green), --color-interactive-hover (lighter green ~#00b57a), --color-text (#333), --color-text-muted (#555), --color-border (green with opacity)
- Syntax colors (vibrant for pink background): magenta, bright blue, orange, purple, emerald green, cyan for keywords/strings/functions/numbers/etc.

**Typography Tokens:**
- Three font stacks (exact fonts determined in Task 2, use placeholder names): --font-heading (serif), --font-body (sans-serif with system fallbacks), --font-code (monospace)
- Fluid type scale using clamp(): --text-h1 through --text-h3 for headings (larger scaling), --text-body, --text-small for content, --text-ui for UI elements (minimal scaling)
- Example: --text-h1: clamp(2rem, 1.7rem + 1.5vw, 2.5rem)

**Spacing Scales (contextual per CONTEXT.md):**
- Content spacing (generous, base-8): --space-content-xs through --space-content-2xl (0.5rem to 4rem progression)
- UI spacing (tight, base-4): --space-ui-xs through --space-ui-2xl (0.25rem to 2rem progression)

**Layout Tokens:**
- --container-max: 900px
- --container-padding: 20px
- Breakpoints as comments (not CSS variables): mobile 480px, tablet 768px, laptop 1024px, desktop 1440px

**Preserve existing color values initially:** Keep current green #00a36c and pink #fdc3c6. Replace Roboto Mono references (but wait for actual font choice in Task 2).

**Structure approach:** Follow existing style.css organization (uses comment headers like /* ========== SECTION ========== */). Add design tokens at the very top before any existing rules.

**Why CSS custom properties not Sass:** Per RESEARCH.md, custom properties preferred for runtime manipulation and GitHub Pages simplicity (no build step required).

<task type="auto">
  <name>Task 2: Integrate Google Fonts and Define Font Stacks</name>
  <files>style.css, index.html, blog/index.html</files>
  <action>
Select specific fonts for the three-font system per CONTEXT.md requirements:

**Font Choices (Claude's discretion within constraints):**
- **Headings**: Bold serif ultra-wide with strong visual impact. Options: DM Serif Display (Google Fonts), Playfair Display (wider variant), or Libre Baskerville (bold weight). Choose DM Serif Display for its ultra-wide bold aesthetic.
- **Body text**: Neutral sans-serif that's readable and unobtrusive. Options: Inter (modern), Open Sans (clean), or Lato (warm). Choose Inter for its excellent readability and modern feel with strong system font fallbacks.
- **Code**: Distinctive monospace that's NOT Roboto Mono. Options: JetBrains Mono (coding-focused), Fira Code (ligatures), or Source Code Pro (clean). Choose JetBrains Mono for its distinctive character shapes and better readability on colored backgrounds.

**Update HTML files:**
In index.html and blog/index.html `<head>`, REPLACE the existing Google Fonts link:
```html
<!-- OLD: -->
<link href="https://fonts.googleapis.com/css2?family=Roboto+Mono:wght@300;400;700&display=swap" rel="stylesheet">

<!-- NEW: -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=DM+Serif+Display:wght@400&family=Inter:wght@400;600;700&family=JetBrains+Mono:wght@400;600&display=swap" rel="stylesheet">
```

**Update style.css font token values:**
Replace placeholder font names in :root with actual font stacks (from Task 1):
```css
--font-heading: 'DM Serif Display', Georgia, 'Times New Roman', serif;
--font-body: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Roboto', 'Helvetica Neue', Arial, sans-serif;
--font-code: 'JetBrains Mono', 'SF Mono', Monaco, 'Cascadia Code', 'Courier New', monospace;
```

**Apply fonts globally:**
Update body and heading selectors to use new font tokens:
```css
body {
  font-family: var(--font-body);
}

h1, h2, h3, h4, h5, h6 {
  font-family: var(--font-heading);
}

code, pre {
  font-family: var(--font-code);
}
```

**Remove all Roboto Mono references:** Find and replace any remaining `'Roboto Mono'` strings in style.css with `var(--font-code)`.

**Why these fonts:** DM Serif Display provides ultra-wide bold serif for visual impact, Inter offers excellent readability with strong fallbacks, JetBrains Mono has distinctive glyphs that read well on pink background (per RESEARCH.md pitfall about colored backgrounds).

**Why font-display: swap:** Per RESEARCH.md, this prevents FOIT/FOUT by showing fallback fonts immediately (from line 452-462).
  </action>

Add desktop-first responsive media queries at the end of style.css with mobile spacing optimization:

**Responsive strategy per CONTEXT.md:**
- Base styles target desktop (1440px+)
- Progressive simplification for smaller screens using max-width queries
- Mobile spacing is "selectively tighter" - reduce spacing more aggressively on small screens

**Add media query section at end of style.css:**
```css
/* ========== RESPONSIVE DESIGN (DESKTOP-FIRST) ========== */

/* Laptop: 1024-1440px */
@media (max-width: 1440px) {
  .page-container {
    padding: 18px;
  }
  
  .blog-grid {
    gap: 1.2rem;
  }
}

/* Tablet: 768-1024px */
@media (max-width: 1024px) {
  .card {
    width: 90%;
  }
  
  .page-container {
    padding: 16px;
  }
}

/* Tablet portrait: 480-768px */
@media (max-width: 768px) {
  /* Reduce content spacing by ~33% on mobile per RESEARCH.md line 929 */
  :root {
    --space-content-xl: 2rem;   /* 3rem → 2rem */
    --space-content-lg: 1.5rem; /* 2rem → 1.5rem */
    --space-content-md: 1rem;   /* 1.5rem → 1rem */
    --space-content-sm: 0.75rem; /* 1rem → 0.75rem */
  }
  
  .page-container {
    padding: 15px;
  }
  
  .blog-grid {
    grid-template-columns: 1fr;  /* Single column */
    gap: 1.2rem;
  }
  
  .card {
    width: 95%;
  }
  
  /* Headings smaller on tablet */
  h1 {
    font-size: clamp(1.75rem, 1.5rem + 1.25vw, 2rem);
  }
  
  h2 {
    font-size: clamp(1.4rem, 1.2rem + 1vw, 1.75rem);
  }
}

/* Mobile: < 480px */
@media (max-width: 480px) {
  .page-container {
    padding: 10px;
  }
  
  .blog-grid {
    gap: 1rem;
  }
  
  .card {
    width: 100%;
  }
  
  /* Further reduce heading sizes on mobile */
  h1 {
    font-size: clamp(1.5rem, 1.4rem + 0.5vw, 1.75rem);
  }
  
  h2 {
    font-size: clamp(1.25rem, 1.15rem + 0.5vw, 1.5rem);
  }
  
  h3 {
    font-size: clamp(1.1rem, 1.05rem + 0.25vw, 1.25rem);
  }
  
  /* Reduce UI padding on mobile */
  .nav-links a {
    padding: var(--space-ui-xs) var(--space-ui-md);
  }
}
```

**Update existing media queries:** Find any existing @media rules in style.css and consolidate them into this new section. Ensure they follow desktop-first approach (max-width, not min-width).

**Why desktop-first:** Per CONTEXT.md, desktop (1440px+) is the optimal/primary experience. Mobile is functional but deliberately simplified.

**Why reduce spacing tokens in media query:** Per RESEARCH.md (lines 816-822), mobile needs more aggressive spacing reduction - updating custom properties in media query cascades to all components using those tokens.

**Why 33% reduction:** Per RESEARCH.md (line 929), this is the recommended reduction ratio for content spacing on mobile (3rem → 2rem, 2rem → 1.5rem).

**Preserve existing responsive behavior:** The business card flip interaction and blog grid should continue working. Focus on spacing, font sizes, and container widths.

## Technical Implementation

### Static 3D Card Depth

**CSS approach:**
```css
.card {
  transform: translateZ(40px);
  filter: drop-shadow(0 10px 15px rgba(0, 0, 0, 0.15))
          drop-shadow(0 20px 30px rgba(0, 0, 0, 0.1))
          drop-shadow(0 30px 45px rgba(0, 0, 0, 0.08));
}

.card:hover {
  transform: translateZ(40px) translateY(-8px);
}

.card.is-flipped {
  transform: translateZ(40px) rotateY(180deg);
}
```

**Key pattern:** Combined translateZ for depth with filter: drop-shadow (multi-layer) for realistic shadow projection. Maintains 3D positioning during flip rotation and hover lift.

### CSS-Only Parallax

**HTML structure:**
```html
<main class="page-container"> <!-- perspective: 1px -->
  <div class="parallax-layer" data-depth="-1">
    <div class="parallax-bg-decoration"></div> <!-- decorative orbs -->
  </div>
  
  <div class="parallax-layer" data-depth="0">
    <div class="card">...</div> <!-- business card -->
  </div>
  
  <div class="parallax-layer" data-depth="1">
    <section class="skills-section-3d">...</section> <!-- skill cards -->
  </div>
</main>
```

**CSS rules:**
```css
.page-container {
  perspective: 1px;
  overflow-y: auto;
  transform-style: preserve-3d;
}

.parallax-layer[data-depth="-1"] {
  transform: translateZ(-2px) scale(3);
  z-index: -1;
}

.parallax-layer[data-depth="0"] {
  transform: translateZ(-1px) scale(2);
  z-index: 1;
}

.parallax-layer[data-depth="1"] {
  transform: translateZ(0);
  z-index: 2;
}
```

**Scale compensation:** scale() values compensate for perspective distortion (further layers appear smaller, so scale up to maintain visual size).

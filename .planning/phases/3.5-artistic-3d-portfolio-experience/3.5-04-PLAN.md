<task type="auto">
  <name>Add reduced-motion support and mobile CSS simplification</name>
  <files>style.css</files>
  <action>
Add mobile optimization media query at end of style.css (before existing mobile queries if any):

```css
/* Mobile: Simplified 3D effects for performance */
@media (max-width: 768px) {
  /* Flatten skill cards - remove 3D transforms */
  .skill-card-3d {
    transform: none !important;
    transition: opacity 0.2s ease;
  }
  
  .skill-card-3d:hover {
    transform: none !important;
    opacity: 0.9;
  }
  
  /* Disable parallax layers - flatten to single plane */
  .parallax-layer {
    transform: none !important;
  }
  
  /* Reduce card perspective for simpler effect */
  .card {
    perspective: none;
  }
  
  /* Keep card flip working but remove tilt enhancement */
  .card:hover {
    transform: translateY(-4px) !important; /* Smaller lift, no tilt */
  }
  
  .card.is-flipped:hover {
    transform: translateY(-4px) rotateY(180deg) !important;
  }
}

/* Accessibility: Respect reduced motion preference */
@media (prefers-reduced-motion: reduce) {
  /* Disable all 3D transforms and parallax */
  .skill-card-3d,
  .parallax-layer,
  .card {
    transform: none !important;
    transition: none !important;
  }
  
  /* Keep flip functional but instant */
  .card.is-flipped {
    transform: rotateY(180deg) !important;
    transition: none !important;
  }
  
  /* Disable particle animations - could add canvas.style.display = 'none' via JS if needed */
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

Per RESEARCH.md lines 274-290 for mobile and reduced-motion patterns. Per user decision from CONTEXT.md: "Mobile handling: Disable mouse tracking on mobile (no touch/gyroscope tracking)".

Note: Particle canvas animation can't be fully disabled via CSS. If needed, add to particle script: if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) { /* skip animation loop */ }

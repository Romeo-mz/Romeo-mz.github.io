<task type="auto">
  <name>Implement mouse tracking for 3D tilt on card hover</name>
  <files>index.html</files>
  <action>
Add mouse tracking script in inline script block before closing body tag:
- Query all .skill-card-3d elements
- For each card, add mouseenter listener setting isHovering flag true
- Add mouseleave listener setting isHovering false and resetting --tilt-x, --tilt-y to 0deg
- Add mousemove listener (only active when isHovering):
  - Wrap calculation in requestAnimationFrame for performance per RESEARCH.md line 203
  - Get card bounding rect
  - Calculate relative mouse position: x = (clientX - rect.left) / rect.width (0 to 1), y = (clientY - rect.top) / rect.height (0 to 1)
  - Convert to rotation angles: rotateY = (x - 0.5) × 40 for range -20 to +20 degrees (per user decision 15-20deg, using 20 for upper bound)
  - Convert Y to rotation: rotateX = (0.5 - y) × 40 for inverted vertical tilt
  - Set CSS custom properties: card.style.setProperty('--tilt-x', `${rotateX}deg`), same for --tilt-y

Per RESEARCH.md lines 577-606 for mouse tracking pattern with throttled events.

Per user decision from CONTEXT.md: "Card hover only (not global page tracking)" and "Medium easing (balanced response time)" - already handled by CSS transition 0.3s ease-out on .skill-card-3d.
  </action>

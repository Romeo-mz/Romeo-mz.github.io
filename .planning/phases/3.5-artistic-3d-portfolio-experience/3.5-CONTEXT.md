# Phase 3.5: Artistic 3D Portfolio Experience - Context

**Gathered:** 2026-02-20
**Status:** Ready for planning

<domain>
## Phase Boundary

This phase transforms the existing portfolio page (index.html) with 3D depth, particle effects, parallax scrolling, and interactive mouse-tracking to create a unique, artistic experience. The flippable business card remains the core element, enhanced with 3D effects. Scope includes: 3D floating skill cards, particle constellation background, layered parallax depth, enhanced card transformations, and 60fps performance optimization.

</domain>

<decisions>
## Implementation Decisions

### Particle System Visual Style
- **Shape:** Constellation dots (star-like points, clean and minimal)
- **Connections:** Lines connect particles to mouse cursor (not auto-connect between particles)
- **Movement:** Medium energy with noticeable drift
- **Density:** Balanced presence (50-80 particles)

### Parallax Depth Arrangement
- **Layers:** 3 layers (foreground + midground + background)
- **Card placement:** Claude's discretion for most effective depth arrangement
- **Intensity:** Moderate parallax movement (noticeable but not dramatic)
- **Trigger:** Scroll-based parallax only (not mouse-based)

### Mouse Tracking Behavior
- **Rotation intensity:** Moderate 3D rotation (15-20 degrees)
- **Tracking zone:** Card hover only (not global page tracking)
- **Response speed:** Medium easing (balanced response time)
- **Mobile handling:** Disable mouse tracking on mobile (no touch/gyroscope tracking)

### Claude's Discretion
- Business card depth layer positioning (foreground, midground, or background) — choose the arrangement that creates the most effective 3D composition
- 3D skill cards presentation (not discussed) — layout, grouping, spacing, animation approach
- Performance optimization strategy (not discussed) — mobile reduction techniques, effect priorities for 60fps

</decisions>

<specifics>
## Specific Ideas

**Particle system:**
- Constellation aesthetic: dots should evoke stars or nodes in space
- Interactive connection: lines should dynamically draw from particles to cursor position as user moves mouse
- Medium energy float gives life without being distracting

**Parallax:**
- 3-layer depth creates classic parallax effect without over-complication
- Scroll-triggered (not mouse) keeps the effect predictable and performance-friendly
- Moderate intensity provides clear depth without motion sickness

**Mouse tracking:**
- 15-20 degree rotation range feels interactive without being gimmicky
- Hover-only activation focuses the effect on the main card element
- Medium easing provides responsive feel without lag or jitter
- Mobile gets simplified experience (no tracking) for performance and usability

</specifics>

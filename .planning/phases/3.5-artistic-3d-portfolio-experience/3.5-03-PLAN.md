Restructure index.html to wrap content in parallax layers:
- Keep canvas (particles) outside parallax structure (fixed background)
- Wrap .page-header in div class="parallax-layer" data-depth="0" (midground - normal speed)
- Wrap .card (business card) in div class="parallax-layer" data-depth="0" (midground per Claude's discretion from CONTEXT.md - card as primary element without dominating)
- Wrap .skills-section-3d in div class="parallax-layer" data-depth="1" (foreground - slower parallax for depth)
- Add empty decorative div class="parallax-layer parallax-bg" data-depth="-1" before .page-container for background layer (faster parallax)

In style.css, implement CSS-only parallax:
- .page-container: add perspective 1px (small value for subtle parallax per RESEARCH.md line 621), height auto (not fixed), overflow-x hidden, overflow-y auto, transform-style preserve-3d
- .parallax-layer: position relative, width 100%, transform-style preserve-3d
- .parallax-layer[data-depth="-1"]: transform translateZ(-2px) scale(3) (background - moves faster), z-index -1 (behind particles which are -1 but fixed)
- .parallax-layer[data-depth="0"]: transform translateZ(0) (midground - normal speed), z-index 1
- .parallax-layer[data-depth="1"]: transform translateZ(1px) scale(0.5) (foreground - moves slower), z-index 2
- .parallax-bg: add min-height 200px, background gradient or subtle pattern for visual depth layer

Scale values compensate for perspective distortion per RESEARCH.md line 636.

Per user decision from CONTEXT.md: "3 layers", "Moderate parallax movement (noticeable but not dramatic)", "Scroll-based parallax only (not mouse-based)".

Alternative if CSS-only parallax causes layout issues: use IntersectionObserver with threshold array per RESEARCH.md lines 659-676, but prefer CSS-only for simplicity.

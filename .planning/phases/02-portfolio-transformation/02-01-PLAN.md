<task type="auto">
  <name>Task 2: Refine Flip Animation Timing and Apply Typography System</name>
  <files>style.css</files>
  <action>
Make two sets of changes:

**Part A: Update flip animation timing** in CARD 3D FLIP section (around line 337):

Change `.card` transition property:
- FROM: `transition: transform 0.8s cubic-bezier(0.4, 0, 0.2, 1);`
- TO: `transition: transform 0.6s ease-out;`

**Why:** User wants "quick start, smooth finish" feel. Research confirms `ease-out` provides crisp initiation with gentle landing. 0.6s duration is polished without feeling rushed (current 0.8s is slightly slow).

**Do NOT change:**
- `.card.is-flipped { transform: rotateY(180deg); }` (flip mechanism)
- Hover/focus transform combinations like `.card.is-flipped:hover { transform: translateY(-8px) rotateY(180deg); }` (correct pattern for preserving multiple transforms)
- Any `-webkit-` vendor prefixes on `transform-style` or `backface-visibility` (needed for Safari/iOS)

---

**Part B: Apply Phase 1 typography variables** to card content:

Replace hardcoded font sizes with Phase 1 custom properties (use existing selectors, just update values):

**Front side headings:**
- `.intro h1` → `font-size: var(--text-h1);` (clamp(2rem, 1.7rem + 1.5vw, 2.5rem) from Phase 1)
- `.intro h2` → `font-size: var(--text-h3);` and add `font-weight: 600;`
- `.intro p` (Devminds line) → `font-size: var(--text-body);`

**Info boxes:**
- `.info-box h3` → `font-size: var(--text-h4);` (if not already using variable)
- `.info-box p` → `font-size: var(--text-body);`

**Back side skills:**
- `.skills-title` → `font-size: var(--text-h2);` and `font-family: var(--font-heading);` (DM Serif Display)
- `.skill-item` → `font-size: var(--text-ui);` (clamp(0.875rem, 0.85rem + 0.125vw, 0.95rem))

**Footer elements:**
- `.social-links a` → `font-size: var(--text-ui);`
- `.flip-hint` → `font-size: var(--text-small);` (if exists) or `font-size: var(--text-ui);`

**Why:** Integrates card typography with Phase 1 design system for consistency. Fluid clamp() scales ensure text adapts smoothly across responsive breakpoints (Phase 1 pattern).

**Do NOT change:**
- Font families already set (DM Serif Display for headings, Inter for body — Phase 1 established these)
- Line heights and spacing (unless they look broken after font size changes)
- Any font properties in blog sections or post content (out of Phase 2 scope)

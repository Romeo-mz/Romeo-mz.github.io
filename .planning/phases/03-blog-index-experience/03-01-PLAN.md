  <action>
In the existing `<script>` block (after `loadBlogArticles` function):

1. Create debounce utility function (300ms delay):
```javascript
function debounce(func, wait) {
  let timeout;
  return function executedFunction(...args) {
    const later = () => {
      clearTimeout(timeout);
      func(...args);
    };
    clearTimeout(timeout);
    timeout = setTimeout(later, wait);
  };
}
```

2. Initialize Fuse.js instance at module level (outside loadBlogArticles):
```javascript
let allPosts = [];
let fuse = null;
```

3. Inside loadBlogArticles, after sorting posts, initialize Fuse:
```javascript
allPosts = posts;
fuse = new Fuse(posts, {
  keys: [
    { name: 'title', weight: 2 },
    { name: 'excerpt', weight: 1 },
    { name: 'tags', weight: 1.5 }
  ],
  threshold: 0.4,
  ignoreLocation: true,
  minMatchCharLength: 2
});
```

4. Refactor post rendering logic: extract DOM update into separate `renderPosts(postsArray)` function that existing code calls. Function should:
- Accept array of posts
- Handle empty array (show "No posts found" message)
- Build HTML string then set container.innerHTML once (not per-post)
- Re-attach click/keydown handlers after innerHTML update

5. Add search input event listener at end of loadBlogArticles:
```javascript
const searchInput = document.getElementById('blogSearch');
const debouncedSearch = debounce((query) => {
  const trimmed = query.trim();
  if (trimmed.length >= 2) {
    const results = fuse.search(trimmed);
    renderPosts(results.map(r => r.item));
  } else {
    renderPosts(allPosts); // Show all if search cleared
  }
}, 300);
searchInput.addEventListener('input', (e) => debouncedSearch(e.target.value));
```
